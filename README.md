# Alivio

Адаптивный одностраничный лендинг сервиса Alivio, который помогает пользователям лучше понимать стресс и управлять им с помощью персонализированного дневника.

## О проекте

Страница сверстана по макету и состоит из нескольких основных блоков:

- навигационное меню;
- главный экран с призывом к действию;
- раздел с тремя шагами работы сервиса;
- история пользователя с видеороликом;
- презентация продукта;
- подвал с навигацией.

Макет адаптируется под разные размеры экрана с помощью медиазапросов.

## Технологии

- HTML5;
- CSS3;
- Flexbox;
- адаптивная верстка;
- методология именования классов БЭМ;
- локальные и подключаемые шрифты;
- HTML5 Video.

## Адаптивность

Основные изменения компоновки выполняются на контрольных точках:

- `1440px` — перестроение карточек и секции с видео;
- `1240px` — вертикальная компоновка навигации и блока продукта;
- `600px` — адаптация меню, заголовков и карточек для мобильных устройств.

## Автор

Учебный проект по верстке адаптивного сайта.
